# Fintrust-Data-Analytics-Week-1
Data Analytics project for the FinTrust Financial Intelligence &amp; Digital Banking Support Solution — AnalystLab Africa Experience Lab Internship Program.
This repository contains my work for the FinTrust Experience Lab, a 4-week multidisciplinary project focused on developing a financial intelligence and digital banking support solution for FinTrust Digital Bank.
Track: Data Analytics Program: AnalystLab Africa Experience Lab

Project Overview
The project explores how customer and transaction data can be used to generate useful business insights, monitor banking performance, understand customer behaviour, and identify patterns that may support risk review and decision-making.
As part of the Data Analytics track, my focus is on transforming the available data into meaningful insights through data profiling, exploratory analysis, KPI development, and dashboarding.

Week 1: Understand → Explore → Define → Plan
During Week 1, I focused on understanding the business problem, reviewing the available datasets, defining analytical questions and KPIs, planning the dashboard, and outlining the analysis approach.
Week 1 Deliverables
* Business Understanding
* Data Understanding & Profiling
* Analytical Questions
* KPI Definitions
* Dashboard Wireframe
* Initial Analysis Plan
The detailed Week 1 submission is included in the Week-1 folder.

Datasets
The project uses two main datasets:
* Customer Data — 1,500 customer records
* Transaction Data — 12,000 transaction records
The datasets contain information relating to customer characteristics, account details, digital engagement, transaction activity, channels, transaction outcomes, locations, and risk-review flags.

Tools
The planned tools for the project include:
* Microsoft Excel
* SQL
* Power BI
* Python/Jupyter Notebook
